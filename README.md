# Data Professionals Survey Dashboard | Power BI

## Project Overview

This project uses Microsoft Power BI to analyze survey responses from data professionals. The dashboard presents insights into salary trends, geographical distribution, programming language preferences, demographics, and job satisfaction.

The goal is to transform survey data into an interactive dashboard that makes it easier to explore patterns across different roles and respondent groups.

## Objectives

- Analyze the geographical distribution of survey respondents.
- Compare average salaries across data-related job titles.
- Identify the most popular programming languages among respondents.
- Compare average salaries by gender.
- Examine reported work/life balance and salary satisfaction.
- Present key survey metrics through an interactive dashboard.

## Dashboard Features

### 1. Country Distribution
Visualizes the distribution of survey respondents across countries.

### 2. Average Salary by Job Title
Compares average salaries across roles such as Data Scientist, Data Engineer, Data Architect, and Data Analyst.

### 3. Survey Respondent Count
Displays the total number of survey responses represented in the dashboard.

### 4. Average Age
Shows the average age of the survey respondents.

### 5. Programming Language Preferences
Compares programming language preferences across respondents, including Python, R, and other languages.

### 6. Salary Comparison by Gender
Presents a comparison of average salaries between male and female respondents.

### 7. Work/Life Balance Satisfaction
Displays the reported work/life balance satisfaction score.

### 8. Salary Satisfaction
Displays the reported salary satisfaction score.
